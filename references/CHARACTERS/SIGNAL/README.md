## What this has to hold

Korinth KI-series combat chassis, black and grey composite, built for function at the cost of subtlety. Has to duck at a door frame. Nathan Zhao is inside it. Moves like something very large trying not to break the furniture.

## How to lock this

1. Generate the canonical image. One figure, full body, neutral pose, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `char-signal-canonical.png`.
3. Paste the description into `block` for `SIGNAL` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
