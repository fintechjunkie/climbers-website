## What this has to hold

Grid contractor, twenty-two years. Narrator of Prologue II. The lens is over the LEFT eye; the notebook is the plot object and appears in five plates.

## How to lock this

1. Generate the canonical image. One figure, full body, neutral pose, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `char-cole-canonical.png`.
3. Paste the description into `block` for `COLE` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
