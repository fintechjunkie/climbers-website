**Status: LOCKED.**

## What this has to hold

Human. Face fully concealed behind a dark mask, a single eye burning at the LEFT socket in a specific orange-gold. Moves with geometric efficiency; counts exits before sitting down. Carries a blade that lights.

## How to lock this

1. Generate the canonical image. One figure, full body, neutral pose, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `char-kimo-canonical.png`.
3. Paste the description into `block` for `KIMO` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
