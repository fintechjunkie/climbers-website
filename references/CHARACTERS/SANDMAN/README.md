# a Sandman

Token: `{{CHAR:SANDMAN}}`
Required file: `char-sandman-canonical.png`

Use `char-sandman-canonical.png` as the required visual reference whenever this figure appears. Preserve the exact face, silhouette, proportions and coloration. Clothing may change only where the wardrobe rows below permit it.

**Status: NOT LOCKED — no canonical image yet.**

## What this has to hold

Sister Silence's people. The threat is entirely in the flatness of the attention — no weapon drawn, no lean-in, in any plate we have specced.

## How to lock this

1. Generate the canonical image. One figure, full body, neutral pose, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `char-sandman-canonical.png`.
3. Paste the description into `block` for `SANDMAN` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
