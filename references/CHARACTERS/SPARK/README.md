## What this has to hold

Human, green and gold. Mechanical RIGHT arm with fresh tool marks at the elbow, integrated deep enough that the shoulder sits differently from the left. Shakes with the mechanical hand by habit. Easy energy of someone whose mind is already made up.

## How to lock this

1. Generate the canonical image. One figure, full body, neutral pose, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `char-spark-canonical.png`.
3. Paste the description into `block` for `SPARK` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
