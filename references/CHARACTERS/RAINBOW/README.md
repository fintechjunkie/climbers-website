# Rainbow

Token: `{{CHAR:RAINBOW}}`
Required file: `char-rainbow-canonical.png`

Use `char-rainbow-canonical.png` as the required visual reference whenever this figure appears. Preserve the exact face, silhouette, proportions and coloration. Clothing may change only where the wardrobe rows below permit it.

**Status: LOCKED.**

## What this has to hold

Runs The Prism, nineteen years. Narrator of Prologue III and present in most of its plates. His face is ALWAYS in shadow under the hat brim — a design choice, not a defect; a pass that lit it came back as an ordinary old man and lost the character. The stolen Bone Patrol optic is the only feature ever visible.

## How to lock this

1. Generate the canonical image. One figure, full body, neutral pose, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `char-rainbow-canonical.png`.
3. Paste the description into `block` for `RAINBOW` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
