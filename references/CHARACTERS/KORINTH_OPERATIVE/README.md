## What this has to hold

Plainclothes, professional, moving with a coordinated looseness civilians do not have. Reads as a group only to someone looking for a group. Not uniformed and not obviously armed.

## How to lock this

1. Generate the canonical image. One figure, full body, neutral pose, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `char-korinth-operative-canonical.png`.
3. Paste the description into `block` for `KORINTH_OPERATIVE` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
