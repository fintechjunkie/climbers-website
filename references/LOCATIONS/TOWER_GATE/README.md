## What this has to hold

Enormous and gold-lit, geometric lines layered back in receding arches the way a cathedral is layered — except it simply stands open and lets you decide. Always open. Visible from The Prism's door on clear mornings. p3 spread 18 and the opener.

## How to lock this

1. Generate the canonical image. One figure, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `loc-tower-gate.png`.
3. Paste the description into `block` for `TOWER_GATE` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
