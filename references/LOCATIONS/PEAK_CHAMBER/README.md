## What this has to hold

Crystalline. Or vast. Or impossibly small — contradictory truths hold here the way they do in dreams or mathematics. Transparent floor with Haven City far below. p1 spreads 1-4, 8-11.

## How to lock this

1. Generate the canonical image. One figure, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `loc-peak-chamber.png`.
3. Paste the description into `block` for `PEAK_CHAMBER` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
