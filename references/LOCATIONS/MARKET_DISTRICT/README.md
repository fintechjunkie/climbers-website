# the Market District

Token: `{{LOC:MARKET_DISTRICT}}`
Required file: `loc-market-district.png`

Use `loc-market-district.png` as the required visual reference whenever this location appears. Preserve the exact layout, palette and construction. 

**Status: LOCKED.**

## What this has to hold

Smooth, airless efficiency — it looks like abundance and functions like a clock. Vendor rows, crowd-flow corridors measured to fractions. p1 spreads 5-7.

## How to lock this

1. Generate the canonical image. One figure, plain
   ground, nothing from a story beat in frame — this is a reference sheet, not
   a plate.
2. Save it in this folder as exactly `loc-market-district.png`.
3. Paste the description into `block` for `MARKET_DISTRICT` in
   `content/roster.json`, and set `locked` to `true`.
4. Run `npm run prompts`. It will start attaching this file to every prompt
   that uses the token.
