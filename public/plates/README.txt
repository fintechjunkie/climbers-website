The filename IS the wiring. Name each file for the slug printed at the top of
its PROMPT.txt, lowercase, .jpg:

  p1-opener.jpg     Prologue I, chapter opener
  p1-s01.jpg  ...  p1-s13.jpg

Square, 1:1. The reader's page is square and the plate fills it edge to edge.
Keep the lower-right ~6% clear — the folio sits there.

If your files come out named something else, drop them in anyway and say so;
they get renamed to the slugs rather than regenerated.

  npm run parse     reports coverage per volume
  npm run dev       then open /climb/p1/read to see them on the page
